# Restaurant review media gate (2026-09-27)

Before giving anyone a review URL, build each restaurant's separate React source with `npm run build`. That runs `build-gate.py` after Vite. The gate fails if the HTML is over 100 kB, the hashed external JS is missing or over 1.7 MB, any image/font/video is embedded as base64 in HTML/CSS/JS, the restaurant-specific 8-second MP4 is absent/unplayable/over 1.2 MB, the hero does not reference that MP4, or its original photo fallback is missing. Each review has its own directory and image/film assets, so an HTML-only bundle cannot recur unnoticed. Keep prior review versions intact. Verify all routes, mobile/tablet/desktop pixels, video playback, the live network asset URLs, canvas rendering and ScrollTrigger count in the browser before handing out the new link. If a metric misses the premium threshold, hold the link and state what remains.

A photo zoom is clearly a film derived from a still, not client-shot video footage. Never use one customer's media on another customer's page. Customer photo permissions must be confirmed before production use.
